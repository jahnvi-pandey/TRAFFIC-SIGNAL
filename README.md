# Traffic Signal Simulator
A simple and interactive Traffic Signal Simulator built using HTML, CSS, and JavaScript. This project demonstrates DOM manipulation, event handling, and basic JavaScript logic by simulating the behavior of a real-world traffic signal.

# Features
- Red, Yellow, and Green traffic lights
- Manual control using buttons
- Dynamic light switching with JavaScript
- Simple and responsive user interface
- Beginner-friendly project

# Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)
